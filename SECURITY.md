# Security and Sensitive Data

Husky Performance is pre-release software and is not yet approved for production use.

Do not post customer information, raw logs, vehicle identifiers, addresses, credentials, encryption keys, private business records, or other sensitive material in public GitHub issues.

For a potential security concern, contact the [Husky Performance Facebook Page](https://www.facebook.com/HuskyPerformanceApp) first and provide only the minimum information needed to establish a private follow-up path.

Nothing in this repository grants permission to test systems, data, accounts, or infrastructure that you do not own or have explicit authorization to test.
